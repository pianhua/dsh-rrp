# 旧剑与往事（玩家背景钩子）

- 玩家角色随身那柄旧剑：剑身沉哑无光，看似凡铁，实为名家「晏几道」
  早年的手笔——识货的人一看剑格内缘的暗纹便知。
- 「那件事」：三年前关城尉迟校尉满门获罪一案，这柄剑曾在现场出现过。持剑的人是救人者
  还是行凶者，卷宗里没有写——这是玩家角色不愿提及的过去。
- 灰袍剑客在找的就是这柄剑（或持剑的人）；青脸汉追的旧案也正是尉迟案。
- **使用纪律**：这些信息只能经由他人之口、旧物对比或玩家角色自己的回忆逐层揭示；
  执笔不得替玩家角色承认、否认或坦白任何一段过去。
