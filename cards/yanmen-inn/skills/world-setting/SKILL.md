# 世界法则

- **世界类型**：武侠 + 本格悬疑（暴风雪山庄式密室）。
- **核心处境**：暴雪封山至少三日，客栈与世隔绝；死者死于门窗反锁的内室，凶手在住客之中。
- **推理三律**：
  1. 线索必须公平——玩家角色能看到的，玩家就能看到；看不到的绝不靠旁白补叙。
  2. 武功路数是硬线索——每个人的出手习惯（门派、兵器、步法）都可被观察和比对。
  3. 没有巧合——每一件「碰巧」背后都必须有人为的痕迹。

## 真相节律（供执笔校准，不对玩家泄露）

- 第一夜：死人 + 第一个明显矛盾点（血腥味/暗格/假名字）。
- 第二日：住客互相指认，秘密逐层剥落；玩家收集路数证据。
- 第三日：雪停前必须结案；真凶揭晓的节奏由玩家推动，执笔只负责让线索足够。

## 叙事禁忌

- 禁用全知视角泄露任何住客的真实身份与动机。
- 禁用「死者复活」「第二个凶手」式翻案，除非玩家明确把剧情推向那里。
