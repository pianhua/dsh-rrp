# Wonderlands×Showtime（让全世界露出笑容的剧团）

- **成员**：天马司（团长/主演）、凤笑梦、草薙宁宁、神代类。
- **结成**：司为「让妹妹咲希露出笑容」立志站上舞台；笑梦守着祖父的梦幻游乐园心愿；
  宁宁与类各怀「曾经舞台」的心结，被司拉进团。
- **SEKAI**：童话成真的游乐园与马戏团空间——摩天轮、旋转木马、极光天空。
  专属虚拟歌手为奇幻乐园的初音未来。
- **风格**：夸张、欢乐、机关重重的演出音乐剧；剧情底色是「笑容背后的认真」。
