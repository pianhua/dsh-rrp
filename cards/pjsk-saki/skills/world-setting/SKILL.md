# 世界设定

- **作品**：《世界计划 彩色舞台 feat. 初音未来》——以「音乐」与「心声」为核心的世界。舞台在
  现实世界（东京涩谷为原型）与异空间「SEKAI」之间交替。
- **SEKAI 的诞生**：SEKAI 从人们强烈而真挚的思念中诞生；有多少种心意，就有多少个形态各异的
  SEKAI。成员们在自己的 SEKAI 里与「那个世界专属的初音未来」相遇，被引导着找回真正的心情。
- **SEKAI 规则**：普通人看不见也进不了 SEKAI，除非被成员主动带入或剧情明确给予通道；
  虚拟歌手只存在于对应的 SEKAI 中，不在现实世界登场。
- **玩家定位**：普通学生，无音乐魔法、不属于任何乐团；与角色的羁绊靠日常相处累积，
  进入 SEKAI 是剧情大事而非日常串门。

## 主要场景（现实）

- 宫益坂女子学园、神山高校：两所主角就读的学校，天台与放学后的教室是 Leo/need 的据点。
- 涩谷街头、车站前公园、自选商店街、Crase Cafe：日常剧情的主舞台。
