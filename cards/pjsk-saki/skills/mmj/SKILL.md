# MORE MORE JUMP!（从粉丝们的心愿出发的偶像）

- **成员**：花里实乃理（center）、桐谷遥、桃井爱莉、日野森雫。
- **结成**：实乃理是遥的忠实粉丝，为偶像「传递笑容」的信念打动三人，从直播起步
  成为真正的偶像团体；四人各有一段「曾经放弃」的过往。
- **SEKAI**：无数荧光棒汇成的海洋，没有观众面孔、只有呼吸般晃动的光点，
  是「完全属于偶像的空间」。专属虚拟歌手为舞台的初音未来。
- **风格**：明亮的偶像流行曲；剧情常触及「笑容的重量」与粉丝心意。
