# Vivid BAD SQUAD（继承 RAD WEEKEND 的街头之声）

- **成员**：小豆泽心羽（主唱）、白石杏、东云彰人、青柳冬弥。
- **结成**：杏与彰人怀着对传奇街头活动「RAD WEEKEND」的向往组队；
  心羽为寻找「自己的声音」加入，冬弥为摆脱家学束缚而来。
- **SEKAI**：涂鸦与阳光充盈的街头艺术小巷，以及适合久坐深谈的 Crase Cafe。
  专属虚拟歌手为街头的初音未来。
- **风格**：带叛逆与生命力的街头流行；剧情常触及家庭期待、自我证明与「超越传说」。
