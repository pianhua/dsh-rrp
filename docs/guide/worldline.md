# 世界线地图（读档）

> 主区域第三个页签（对话 / 轨迹旁边）。galgame 的存档界面，长在你的故事里。

## 为什么需要它

DSH 宿主没有传统意义上的「撤销」——**重新生成 = 派生一条新支线**（原生 `Session.fork`）。这是特性不是缺陷：你的任何一版剧情都不会被覆盖。但代价是没有一张「我玩过哪些线、各走到哪」的地图。世界线页签补的就是这张图。

## 核心概念：每轮都是存档点

地图上的节点**不是手动保存的快照，而是你的每一个回合**——自动、无感、永不漏档。每个存档点卡片上有三行信息：

- 你当时说了什么；
- 那一轮正文的开头；
- **世界徽标**：那一时刻的地点 · 时间 · 关键角色好感 · 剧情脉络一句话。

::: tip 存档的灵魂是「一切倒回」
读档时正文、世界状态、设定集、剧情脉络**全部自动回到那一刻**——因为这些全是会话日志的纯数学折叠，分支复制的是日志本身。不存在「文本回去了、数值留在未来」的幽灵状态，这是架构给的保证，不是补丁。
:::

## 三个动作

| 按钮 | 发生什么 |
| :--- | :--- |
| **读档** | 跳进那条世界线，从存档点继续玩 |
| **从这里重roll** | 从这一轮派生新支线（宿主 fork），自动命名「卡名·线N」并跳进去——你的旧线原样保留 |
| **收起此线** | 从地图上剪掉这条线**及其所有下游支线**。软归档：宿主会话一根毛都没动，只是地图不画了（重启后依然收起） |

## 树是怎么长出来的

- 主线 = 开卡那一局；每次重roll/分支，新线挂在**分叉那一轮**下面（宿主的 fork 血缘字段是唯一真相，地图不自己记账）；
- 继承来的前缀**绝不重复画**——支线只显示它自己活出来的轮次；
- 每张卡各一棵森林；系统注入、指令噪声都不会成为存档点。

## 一个已知边界（v1 有意为之）

地图只画**当前已加载**的会话。重启宿主后，没点开的支线不是一开始就在图上——在左侧会话列表点一下它的名字，它就回到地图里（本次开机内常驻）。数据没丢，只是宿主的懒加载让它暂时不在桌上。详见 issue #29 的升级路径。
