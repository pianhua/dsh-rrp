# 世界线（分支管理）

> 会话内第三个页签（对话 / 轨迹旁边）。左栏是你玩出的所有分支，右栏是选中分支的每一回合。

## 为什么需要它

DSH 宿主没有传统意义上的「撤销」——**重新生成 = 派生一条新支线**（原生 `Session.fork`）。这是特性不是缺陷：你的任何一版剧情都不会被覆盖。但代价是需要一个地方看清「我玩过哪些线、各自走到了哪、每一轮发生了什么」。世界线页签就是这个地方。

## 诚实的前提：宿主没有「回档」

DSH 不提供把一条会话倒回某个历史回合再继续的能力（也没有会话删除）。所以世界线对「过去」只提供两个诚实的操作：

- **查看该回合**：在回合列里回看任何一轮的你说了什么、正文写了什么、世界状态长什么样；
- **从此分叉**：从那一轮派生一条全新的支线继续玩（自动命名「卡名·线N」，可事后改名），旧线原样保留。

任何声称「回到第 N 回合继续」的按钮在这里都不存在——那是假承诺。

## 核心概念：每轮都是存档点

右栏回合列的每个节点**不是手动保存的快照，而是你的每一个回合**——自动、无感、永不漏档。每个节点上有：

- **回合号 + 你的输入摘要**；
- **正文摘要**（该轮正文开头，悬停看全文提示）；
- **节点徽标**：那一刻的地点 · 时间 · 关键角色好感前三 · 剧情脉络一句话；
- **归因行**：这轮的状态是谁记的（开局 / 你 / 状态推演 / 月停）、是继承自父线还是本线产生、变了多少条。状态推演是异步的——它追上了哪一轮，徽标就精确落在哪一轮。

当前所在的回合会高亮「当前回合」。

## 分支操作

| 操作 | 发生什么 |
| :--- | :--- |
| **从此分叉**（选中回合） | 从这一轮 `Session.fork` 派生新线，确认层可命名，完成后跳进去 |
| **重命名** | 改分支显示名（宿主会话标题同步） |
| **收起此线** | 收起这条线**及其全部下游支线**（有确认层）。软归档：宿主会话一根毛都没动，组底「已收起」区可随时恢复 |
| **导出** | 把整条会话导出为小说（md/txt） |
| **打开** | 跳到那条线的会话继续玩 |

## 树是怎么长出来的

- 主线 = 开卡那一局；每次分叉，新线挂在**分叉的那一轮**下面（宿主的 fork 血缘字段是唯一真相，插件不自己记账）；
- 继承来的前缀**绝不重复画**——支线只显示它自己活出来的轮次；
- 每张卡各一组分支；回合号跨血缘连续，几百回合的长档分叉也挂在正确的位置；
- 未加载的冷支线**按真实分叉点**精确挂载（经宿主 session-query 读血缘）；确实解析不出位置的，诚实标注「位置未知」，不再假装挂在父线末尾。
