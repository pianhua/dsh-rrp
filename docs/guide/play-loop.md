# 游玩循环与界面

> 一局游戏里发生了什么，以及你在屏幕上看到的每一块是什么。

## 一轮之内：三智体分立

你每发一条消息，幕后按顺序发生三件事：

```text
你的行动
   ▼
① 叙事执笔（Author）      —— 只写正文：NPC 的言行、环境的呼吸。
   │                        铁律：绝不替你行动、绝不替你说话、
   │                        绝不写数值和系统噪声。
   ▼
② 状态推演（Chronicler）  —— 后台异步：这一轮世界里实际改变了什么？
   │                        好感、伤势、物品、地点、关系、长期事实，
   │                        更新进世界状态（右侧栏随之刷新）。
   ▼
③ 你检视、随手纠偏        —— 不满意状态里哪个数？直接改。
                            下一轮执笔无条件以你改后的为准。
```

还有一个可选的第四位：**剧情脉络（Summarizer）**，每隔 N 轮（默认 8）在后台把长线浓缩成四维罗盘——主线目标 / 核心矛盾 / 重大转折 / 伏笔危机——执笔动笔前先看罗盘，长篇不跑偏。用 `/summary` 命令可随时开关或改频率。

## 界面地图

| 位置 | 名称 | 干什么 |
| :--- | :--- | :--- |
| 主区域 · 对话 | 原生聊天流 | 正文与你的行动都在这里，DSH 原生渲染 |
| 主区域 · 轨迹 | 原生轨迹 | 每一步工具调用与耗时的流水账 |
| 主区域 · **世界线** | [存档地图](/guide/worldline) | 所有剧情分支可视化，读档/重roll 入口 |
| 右侧栏 · **世界状态** | 动态看板 | 角色/物品/场景/事件/关系网 + 就地修改 |
| 右侧栏 · **设定集** | 沉淀知识 | 游玩中确立的新设定，草稿→确认流程 |
| 右侧栏 · **副驾驶** | OOC 幕僚 | 咨询、代劳、撤销，你的私人频道 |
| 左侧栏 · 卡片展厅 | 开卡入口 | 浏览卡包、覆写主角名、开局 |

## 世界状态：五个核心维度

- **characters 角色**：每人好感度（0-100）、情绪、外貌、状况；
- **inventory 物品**：数量与备注；
- **scene 场景**：地点 / 时间 / 天气；
- **flags 长期事实**：跨幕仍然成立的事实与秘密（「某人的真实身份 → 前朝影卫（玩家尚未知情）」）；
- **relations 关系网**：谁和谁是什么关系（主仆/猜忌/同盟），玩家一律记作「玩家」。

状态推演觉得四域装不下时，还可以**自创追踪维度**（魔法值、声望等级、诅咒倒计时……），出现在看板自定义区。

## 玩家矫正：无锁，就事论事

改状态的哲学极其朴素：**AI 更新 → 你看一眼 → 不满意直接改 → 下一轮以你的为准**（最后写入获胜）。没有锁、没有解绑、没有冲突仲裁那套旧包袱。

## 命令

| 命令 | 作用 |
| :--- | :--- |
| `/summary` | 开关剧情脉络，或 `/summary every 6` 改频率 |
| `/lore <主题>` | 让知识起草智体把某主题沉淀为设定集草稿（你去设定集页签确认） |
