# 月停：全知幕僚

> 右侧栏第三个页签。你的私人 OOC 顾问——她什么都知道，也什么都敢聊。

## 她是谁

「月停」是站在**玩家这一侧**的全知幕僚，以出戏（OOC）视角陪你玩。与执笔（Author）的关系一句话说清：

| | 叙事执笔 Author | 月停 Copilot |
| :--- | :--- | :--- |
| 视角 | 世界内部，第三人称小说 | 世界之上，出戏咨询 |
| 知道秘密吗 | 只演「此刻可感知」的 | **全知**：设定、暗线、身份、走向 |
| 会剧透吗 | 永不（信息差是卡的核心玩法） | **对玩家永不保密**——问什么答什么 |
| 写正文吗 | 写 | 绝不代写正文 |

她拿到的资料：卡包设定、当前世界状态、剧情脉络、已有设定集、最近正文 + 你们的对话历史。

## 能问什么

- 「米娅的真实身份和秘密是什么？」——直答，分层次讲；
- 「我现在该做什么？」——给二三个**结合当前状态与脉络**的具体破局方向，说明每个为什么可行；
- 「这条禁忌线/复仇线怎么展开？」——OOC 策略咨询按同一创作授权完整作答，不回避、不说教、不加警告。

## 能代劳什么

用自然语言下指令，她会真的执行（不是嘴上答应）：

- **改世界状态**：「把天气改成大雨，米娅好感 80」→ 她生成动作指令块，宿主校验后执行，改动走与玩家矫正相同的发布通道，账本归因 `copilot`；
- **起草设定集**：「把她的家族背景整理成一条设定」→ 只生成**待确认草稿**，你在设定集页签点确认才生效——知识入库的控制环永远在你手里。

## 一键撤销

每次代劳前自动拍下世界状态快照。点页签顶部的 **一键撤销**：数值回滚到改动前——但历史账本**两条都留**（诚实撤销：回滚也是一次新发布，不是抹除记忆）。每轮一张快照，保留最近 10 次。

## 几条边界

- **她是你的私人频道**：对话内容绝不进入会话日志，执笔看不到你们聊了什么；
- **跟随当前模型**：会话用什么模型她就用什么，不另设开关；
- **世界线隔离**：支线 fork 不继承她的历史——那条线上她没陪过你；
- **历史持久**：存在宿主存储域（插件私有记录，宿主负责原子落盘），重启宿主、刷新页面都在；顶部垃圾桶可清空。
