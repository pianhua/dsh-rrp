# 快速上手

> 30 分钟从安装到开第一局。

## 你需要什么

- **DeepSeek Harness（DSH）**：本插件是 DSH 的原生插件，不是独立软件。先按 [DSH 官方方式](https://deepseek.com) 安装好 `dsh` CLI 并能启动 web 界面；
- 一个能用的模型渠道（DSH 里配好 provider 即可，插件跟随会话当前模型，不另设）；
- 一台你自己的电脑——这是**单人单机**玩具，数据全在本地。

## 安装插件

```bash
# 在 DSH 里登记本插件（发布后）
dsh --profile web plugin add dsh-rrp

# 或本地开发方式（源码仓库）
git clone <本仓库>
cd dsh-rrp && pnpm install && pnpm run build
pnpm run link:dev          # 链接进 rp-dev 开发 profile
dsh --profile rp-dev --port 3099 --no-open
```

启动后打开 DSH 网页界面，左侧导航会出现 **卡片展厅**，即说明挂载成功。

## 开第一局

1. 点左侧栏 **卡片展厅**；
2. 挑一张卡（自带官方卡：`女仆大小姐` 轻松纯爱喜剧 / `雪夜雁门客栈` 暴风雪山庄悬疑），右侧看设定、技能清单与开场白预览；
   - 手上有 SillyTavern 卡？展厅里点 **导入角色卡**，丢进 PNG 或 JSON 导出文件即可转成原生卡包（详见[迁移清单](/authoring/tavern-migration)）；
3. （可选）**本局主角名**：填了就用你的名字覆写卡里声明的主角名——只影响本局，留空沿用卡声明；
4. 选一个工作区（或不分），点 **开始这一局**；
5. 会话自动创建并进入，第一幕开场白已经写好——直接输入你的行动，故事开始。

## 怎么玩

把你当作**小说的主角**，不是跑团的玩家：

- 直接打字说动作、对白、心里想说的话——像写小说一样描述即可；
- 想加速剧情可以下指令（如「跳到第二天」「让她进门」），执笔会让世界回应这个指令而不是机械执行；
- 括号里塞设定补丁（如「（他的刀其实是家传御制）」）会被悄悄折进描写；
- 每轮正文之后，右侧栏 **世界状态** 会异步刷新出这一轮改变了什么。

::: tip 不知道往哪走？
打开右侧栏 **月停** 页签问她——她全知，设定、秘密、破局思路都聊，还能替你改状态。见 [月停](/guide/copilot)。
:::

## 玩砸了怎么办

没有「玩砸」。想重来：打开 [世界线地图](/guide/worldline)，找到那个存档点，**读档**或**从这里重roll**。你的每一条支线都被保存，永不覆盖。
