# Triage labels

Matt Skills 的角色名与本地 Markdown 票据中的 `Status:` 值使用同一组字符串：

| Matt Skills 角色 | 本地值 | 含义 |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | 尚未完成需求判断 |
| `needs-info` | `needs-info` | 等待补充事实或答案 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人亲自决定或操作 |
| `wontfix` | `wontfix` | 明确不处理 |

`claimed` 与 `resolved` 是本地票据的执行状态，不替代上面的 triage 角色。
