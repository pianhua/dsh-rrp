# DSH-Chronicle 系统设计规范（DESIGN.md）

> **文档定位**：`dsh-rrp` 的**全局唯一产品目标规格与交互基线**。  
> 本规范彻底摒弃传统酒馆（SillyTavern）的陈旧劣根性与过度基建的包袱，确立面向 DeepSeek Harness 的全新一代交互小说与动态世界模拟形态。

---

## 1. 核心定位与代际跃迁

`dsh-rrp` 是挂载在 DeepSeek Harness（DSH）上的**原生单机沉浸式角色扮演插件**。

### 1.1 根除传统酒馆的五大劣根性
1. **彻底告别上下文无脑堆砌（Context Stuffing）**：
   - 绝不把数万字设定一股脑塞进上下文；
   - 全面拥抱现代大模型训练时即原生支持的 **Skills 机制**，只在必要时按需查询或渐进展开。
2. **彻底告别死板正则激活世界书（Regex Lorebook）**：
   - 淘汰关键字正则匹配；
   - 设定全量 Markdown Skill 化（如 `skills/return-inn/SKILL.md`），模型根据自然语义与剧情意图自主调取。
3. **彻底告别翻页伪分支（`< 1/3 >`）与幽灵状态**：
   - 重新生成 = 派生新的 DSH 会话分支（Session Fork）；
   - 状态通过 `sessionProjections` 实时计算，切换分支时状态严丝合缝重放，数学上杜绝“文本回退、数值留在未来”的穿帮现象。
4. **彻底告别长线叙事流水账（Plot Drift）**：
   - 引入轻量级 **Summarizer Agent（大局编年智体）**，每隔固定轮次（如 5~10 轮）在后台浓缩提炼四维大局观（主线总目标、当前核心矛盾、重大转折、伏笔危机）；
   - 玩家可根据剧本长短随心开启或关闭该功能。
5. **彻底杜绝替玩家代打发言（Puppeteering）**：
   - Author Agent 的唯一最高铁律：只描写 NPC 的言行与环境氛围，严禁替玩家决定动作、对白与心理。

## 2. 交互面规范：无缝融合的 DSH 原生工作台

拒绝自制割裂的外部网页，玩家体验与 DSH 原生体验浑然一体：

### 2.1 主对话区：宿主原生渲染（已裁决撤回自定义排版）

- 玩家依然在 DSH 原生聊天窗口中游玩；
- ~~依托 DSH 的轻量 CSS 样式微调，正文呈现出舒展、优雅的文学段落排版；打字机流式输出~~
- **2026-09-18 裁决**：自定义正文排版/沉浸视图已撤回（同「不覆盖宿主主题」一条理由）——正文渲染完全交给 DSH 宿主原生实现，插件不做任何对话区样式注入；流式输出观感以宿主为准。曾实现的 `story-view.tsx` 沉浸视图已删除，不再恢复。

### 2.2 右侧栏（DSH sidebarRight）：动态世界看板
- 注册为 DSH 原生右侧栏的一个常驻 Tab：**【世界状态 (WorldState)】**；
- **透明展示四大核心维度（且支持卡包自由扩展）**：
  - `characters`：角色好感、情绪波动、外貌/衣着变化、身体伤势；
  - `inventory`：随身物品、关键信物、道具状态；
  - `scene`：当前地点、时间流转、气候环境；
  - `flags`：已触发事件、知晓的秘密、承诺与誓言。
- **玩家矫正（Player Correction，简单自然时序流）**：
  - 玩家在右侧栏直接点击任何数值或描述，就地修改纠偏；
  - 修改无锁、无复杂校验，直接记录为当前最新切面；
  - 下一轮 Author Agent 动笔前，无条件严格以玩家修改后的最新状态为事实依据。

### 2.3 导航：故事与卡包管理
- 提供轻量级入口：**【编年史 (Chronicle)】**——宿主帧没有独立「顶栏」slot
  （0.1.6-alpha.2 实测结论），入口落在宿主左栏面板导航（`sidebar.panellist`），
  与宿主原生导航保持同一观感；
- 支持浏览原生卡包，预览开场白与人设，点击即可直接基于该卡包新建一个沉浸会话。

## 3. 三智体权能分立矩阵

```text
玩家行动输入 (Player Action)
     │
     ▼
[Step 1: Author Agent 创作正文]
     ├─ 只读消费当前最新 WorldState
     ├─ 遵循第三人称文学创作规范，严禁替玩家发言
     ├─ 按需调用 DSH Skills 调取设定（或依赖系统预取）
     └─ 打字机实时流式交付文学正文到主会话
     │
     ▼
[Step 2: Chronicler Agent 智能推演状态]
     ├─ 异步任务挂载到 ctx.jobs 后台执行
     ├─ 具备独立思考与冷静客观态度的 Agent
     ├─ 提取物理世界、人物心理、关系的客观变动，按需扩充词条
     └─ 提交状态更新，驱动右侧栏状态平滑刷新
     │
     ▼
[Step 3: 玩家随心检视与自然修正]
     └─ 玩家可随意在右侧栏手改任何数值（下一轮 Author 严格消费）
     │
     ▼
[Step 4: (可选/可关) Summarizer Agent 宏观罗盘]
     └─ 每 N 轮后台运行一次，提炼四维大局观，防止长篇剧情偏航
```

## 3.5 副驾驶（Copilot）：全知幕僚（OOC）

右侧栏第三个常驻页签【副驾驶】，独立于主对话区的玩家私人咨询频道：

- **全知视角**：完整知晓卡包设定、人物秘密与剧情走向，玩家随时咨询设定、动机、逻辑与破局思路，直答不保密；
- **可代劳**：通过一个 fenced 动作指令块（`update_world_state` / `draft_sediment`）经宿主路由执行——状态修改走与玩家矫正相同的 `publishState` 通道（账本归因 `actor: 'copilot'`），典籍整理只进**待确认草稿**（D8 控制环不被绕过）；
- **主客分离**：对话历史存插件私有 JSON（`<dshHome>/.dsh-rrp/copilot/<sessionId>.json`），绝不进会话日志；SSE 流式打字机输出，跟随会话当前模型（不做切换器）；
- **诚实撤销**：撤销 = 发布一次还原快照的新状态（值回滚、历史留痕），一轮一张快照、保留最近 10 次；
- **世界线隔离**：按会话 ID 存储，fork 出的新支线不继承副驾历史（旧分支历史原样保留），副驾对话是玩家私有频道，不属于世界状态。

## 4. 知识体系：全面拥抱 DSH Skills

- 彻底淘汰旧酒馆 Lorebook 的陈旧概念与冗余格式；
- 知识资产统一遵循 DSH Skill 规范（包含名称、描述、触发场景与详实 Markdown 说明）；
- 模型具备自主工具调用与技能加载权能，在面对未知势力、特殊功法或场景规则时自主按需调取，天然适配现代大模型的高级认知机制。

---

## 5. 世界线拓扑：原生 Fork 与 Synapse 协同

- 任何重新生成或分支尝试，均映射为 DSH 原生的 `Session.fork`；
- 兼容 `dsh-synapse` 会话地图画布，分支清晰可视化；
- 由于世界状态由 `sessionProjections` 基于会话事件流纯数学折叠，当玩家在不同分支之间切换时，状态百分之百精确重放，绝无幽灵状态。
