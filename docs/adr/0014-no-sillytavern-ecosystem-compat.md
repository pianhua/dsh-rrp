# 不兼容酒馆卡生态

> 状态：接受（经 ADR 0026 修订强化为「完全自有格式」）
> 原编号：D14 · 索引见 [README.md](./README.md)
> 最后复审：2026-10-16 · 复审周期 180 天


**决策**：不选择直接兼容酒馆生态。未来**直接靠 AI 进行转译**，把酒馆卡转成适配我们自己格式的卡。

**含义**：
- 核心引擎零酒馆字段解析代码
- 转译是独立工具 / Skill 的职责，不是引擎职责

**修订（2026-09-27，所有者拍板，见 D26）**：卡包是**完全自有格式**——与酒馆卡格式无任何运行时兼容义务；酒馆卡仅为一次性导入转译的数据来源，导入后即为本格式公民：不跟踪酒馆版本、不支持回导、运行时不解析酒馆字段。导入转译工具保留（`card-import.ts` + 展厅入口），属本决策「转译工具」职责范围内的已登记形态。
