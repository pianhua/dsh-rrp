# 月停升格为玩家私属幕僚（原题：副驾驶升格为玩家私属总管家；issue #33）

> 状态：接受（命名经 ADR 0022 修订为「月停」）
> 原编号：D19 · 索引见 [README.md](./README.md)
> 最后复审：2026-10-16 · 复审周期 180 天


> **命名注（2026-09-20，D22）**：本文标题中的「副驾驶 / 总管家」为当时用词，现已**退役**；玩家可见中文名统一为**月停**，代码标识符 `copilot*` / `steward-*` 保持不变。下文历史正文保留原措辞以备查。

**决策**：Copilot 从「RP 局内 OOC 幕僚」升格为「玩家私属幕僚」：全知（本局 + 整个项目）、绝对服从玩家本人、跨次元服务——剧情内代劳（改状态、起草设定）与剧情外项目维护（卡包修订、文档备忘）是同一类指令。落地为三件套：提示词身份升格、管家技能根（`presets/rp/skills/steward-*`，随物化进基础与全部卡包 preset）、动作词汇扩展（`propose_card_edit` / `propose_doc_note` 走「暂存 → 玩家确认 → 落盘」）。

**理由**：项目文档（docs/ 11 页）已成体系，管家具备维护项目本身的知识基础；玩家需要一个只对本人负责的单一入口，而不是分散的幕僚/编辑器/文档三套交互。

**红线（与升格同时拍板）**：
- 管家**绝不代写正文**（Author 领域）、**绝不替玩家做游戏内决定**——管世界，不管玩家的灵魂；
- 一切落盘改动**必须玩家确认**（steward-proposals 暂存 → 面板确认），绝不静默写文件；
- **只写用户卡目录**（`<home>/.dsh-rrp/cards/`）：随包分发的卡包只读，路径拒绝 `..` 逃逸与 .md/.json/.txt 之外扩展名；
- 管家知识走 D7 Skills 渐进披露（三个 steward-* 技能包），不把文档硬塞进上下文；
- 世界状态改动维持既有可撤销账本；卡包写盘的撤销（旧内容已内存存档）UI 未接，列为 P2。
