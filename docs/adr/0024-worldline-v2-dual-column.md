# 世界线 v2 重做：拓扑与摘要解耦的双栏视图（2026-09-25 拍板）

> 状态：已实现（一期交付并通过真机验收）
> 原编号：D24 · 索引见 [README.md](./README.md)
> 最后复审：2026-10-16 · 复审周期 180 天


**背景**：重做前勘察（源码 + 宿主 0.1.6-alpha.2 逐条核实）确认现有实现存在结构性 bug：① digest 500 回合上限与 fork 切口（seedTurns）计算冲突，长会话切口必错位；② 异步 Chronicler/剧情脉络的徽标不读 `stateFoldSeq`/`summaryTurn`，永远糊在尾节点；③ 徽标只增不删，与 WorldState v2 删除语义不兼容；④ 冷线节点挂父线尾部而非真实分叉点；⑤ 「读档」只打开会话末尾，不回到选中回合；⑥ V2 状态时间线（修改者/继承来源/变化数）完全不接入。

**决策（16 题拷问访谈全部按建议锁定）**：

1. **呈现范式**：galgame SVG 流程图退役。改为**双栏**——左栏分支列表（按卡分组），右栏选中分支的**回合列**（虚拟化，玩家摘要 + 正文摘要 + 状态变化标记 + 节点徽标全密度）。一期不保留流程图；二期视需要以「全图概览」副视图评估回归。
2. **页签归宿**：维持 `conversation.view` 会话视图第三页签（与 Chat、宿主轨迹并列），不另开全局面板。
3. **读档诚实语义**：宿主无 rewind、亦无会话删除 API。「查看该回合」= 本视图内渲染历史回合；「从此分叉」= `fork(atSeq)` 派生新线。不提供假回档，不设删除。
4. **拓扑与摘要解耦（三根支柱重建）**：
   - 分支拓扑只信 `header.parentSession` + `inheritedEventCount`（冷会话经宿主 `sessionQuery` 补读），与 digest 的回合上限彻底解耦；
   - digest 改**绝对回合计数**：`nextTurn` 单调计数、`seedTurns`（=首个本地回合号）在首个本地玩家消息到来时固化；回合徽标按 `worldStateTimelineBatch.provenance.storyTurn` → `stateFoldSeq` 映射 → 尾节点的优先级精确对齐；徽标从当前 WorldState/剧情脉络**全量重建**（支持删除语义）；
   - V2 状态时间线批次接入节点：每回合显示修改者（开局/玩家/Chronicler/月停/系统/未知）、`inherited`/`local` 来源与变化数。
5. **fork 切口保护**：插件监听 `session/created`（`parentSession` + `isSeeded` + 非 subagent），向**父线**追加一条 `source.rrp.worldlineForkCut` 插件通知（追加式、走既有状态发布通道）；父线 digest 折叠该切口回合号，digest 上限裁剪时**永不裁掉切口回合及其前一回合**，保证子线永远有挂载点。
6. **冷支线**：经 `sessionQuery`（`listSessions` 表头 + 必要时 `readSession` 读 `inheritedEventCount`）解析真实分叉切口精确挂载；解析不出（父线亦为冷、或切口已超父线保留窗）时**诚实标注「位置未知」**，按谱系挂最近已知祖先，不再伪装父线尾部。
7. **交互闭环**：分叉确认层带命名输入框（自动命名兜底，可事后手动重命名）；「当前位置」精确到当前回合（`isHead`）；收起 = 该会话 + 全部下游，需确认层，**客户端补恢复入口**（服务端接口本已支持 `hidden:false`）；订阅投影自动刷新，告别手动刷新；fork/hide 失败有明确错误提示。
8. **红线重申**：不发明会话事件类型、不自建分支数据库、不物理删除宿主会话；状态继续寄生 `user/message` 的 `source.rrp`；冷会话数据只走 `sessionQuery`。

**宿主关系**：宿主原生「轨迹」页签 = 单会话执行轨迹（请求/模型/工具/token），世界线 = 跨会话拓扑 + 领域视角，**互补不替代**（D21 同一逻辑：各自渲染面，不往别人呈现里掺东西）。

**分期**：一期 = 数据层修复（决策 4/5/6）+ 双栏交互闭环（决策 1/2/3/7）；二期 = 全图概览、分支对比、导出扩展。本期实现一期。

**实现状态（2026-09-26 交付）**：一期完成并通过真机验收（宿主 0.1.6-alpha.2 + 内置浏览器）。验收中修复五个真 bug：① `diffWorldState` 全局字段变更产出显式 `objectId: undefined` 被宿主事件日志拒绝（Chronicler 整轮失败）；② Chronicler 省略空集合的回复未做信封补全（确定性填充缺失集合）；③ 折叠器把无父会话的主线也标 `位置未知`；④ 分叉确认层回合标签错用 `branch.latest`（应为选中节点）；⑤ 宿主 `readSession` 对 seeded 会话必抛（宿主缺陷，落盘 HOST_SEAMS D14）——冷 fork 切口改由 fork 时刻的切口缓存（cuts 表）精确供给，另加卡归属索引（cards 表）救治冷主线。遗留：cuts 表建立前 fork 的旧冷线仍显示「位置未知」（诚实降级，打开一次后其卡归属入索引）；宿主 readSession 修复后可恢复经宿主解析。
