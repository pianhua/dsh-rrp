# WorldState 近期状态与剧情脉络高维视角分工 + 月停定名（2026-09-20 拍板，2026-09-23 修订）

> 状态：接受（2026-09-23 修订决策①）
> 原编号：D22 · 索引见 [README.md](./README.md)


**决策①（权威与职责边界，2026-09-23 修订）**：Author 同时消费卡包/Skills、WorldState 与剧情脉络；权威按内容种类分工，不排一个全局总序：
- **卡包与 Skills** 是硬设定、世界规则和不可随短期状态漂移的正典依据。
- **WorldState** 是世界近期、当前且可行动的状态，包含具体事实、角色认知、近期目标与活跃矛盾。近期目标是仍可行动的事项；活跃矛盾记录对立双方、利害和当前状态。目标完成或放弃、矛盾解决或放弃后，从当前活跃状态关闭，历史进入持久状态时间线。
- **剧情脉络（Summarizer）** 提供高维、较长线的剧情视角：宏观目标、跨阶段矛盾、重大转折与长期伏笔，用于保持故事方向及整体世界观一致；它不能覆盖当前 WorldState 或玩家矫正。
- 角色认知记录描述角色知道、相信、怀疑、听闻或误解什么；它记录角色的认知状态，不改变客观世界事实。
- **玩家矫正**仍遵循 D6 的自然时序、无锁和最后写入生效；对当前事实和近期目标/矛盾，下一轮 Author 以矫正后的 WorldState 为准。硬设定仍以卡包/Skills 为准，剧情脉络负责长线方向。

**修订理由**：所有者确认 WorldState 的核心思想是近期状态；活跃目标与矛盾也容易变化，须由 WorldState 维护。Summarizer 不再负责重复维护这些近期事项，而是提供更高维度、较长线的剧情视角，帮助叙事不偏离整体世界观。原 D22 将“总目标、活跃矛盾、伏笔”整体交由剧情脉络维护的边界已被本次修订取代。

**决策②（命名）**：Copilot 玩家可见中文名统一为**月停**；英文代码标识符（`copilot*` / `actor:'copilot'` / `StewardProposal` / `steward-*`）为稳定契约不动，英文界面显示 `Copilot`。旧词 副驾驶 / 总管家 / 顾问 退役。

**后续同步**：WorldState 与剧情脉络的字段、状态生命周期、界面呈现和 Author 提示词将在本次设计对齐完成后统一更新；在此之前，本条为最新决策依据。
