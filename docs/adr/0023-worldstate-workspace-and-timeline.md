# WorldState 工作区与持久时间线（2026-09-24 确认，待实现）

> 状态：已实现（WorldState v2 Phase 1–9 交付）
> 原编号：D23 · 索引见 [README.md](./README.md)
> 最后复审：2026-10-17 · 复审周期 180 天


- WorldState 注册为会话视图页签，在主区域提供完整工作区；右侧栏保留完整编辑能力，两处使用同一会话草稿。
- 主工作区采用当前局势概览 + 可折叠/搜索/筛选的板块结构；概览优先显示场景、在场角色、近期目标和活跃矛盾。右侧栏使用适合窄空间的折叠和精简控件，但数据能力不缩水。
- 两处未保存草稿在同一会话内共享；离开页面不丢。切换 Session 前必须选择保存、放弃或留在当前会话；草稿不跨 Session、不在刷新后额外持久恢复。
- 保存前展示变更摘要，玩家确认后提交。Chronicler 新投影到达时，禁止编辑；已有草稿合并未编辑字段、保留玩家已编辑字段，并明确提示后台状态更新。
- 新会话从开局状态建立时间线基线；之后每次实际保存/推演批次形成一条分组变更事件，记录修改者、回合/现实时间和字段旧值/新值。时间线只读，可从字段详情进入并按回合、修改者、对象/字段、变更类型筛选，不提供回滚或历史点读档。
- 时间线修改者固定为卡包初始状态、玩家、Chronicler、月停、手动系统操作；缺失信息显示未知，不伪造回合号或归因。
- 删除仍被关系、目标、矛盾或事件引用的追踪对象时，默认阻止并指出关联项；玩家必须先处理引用，或明确确认删除后的引用处理。归档不改写历史，历史引用继续显示对象名称并标记已归档。
- 不因文本过长静默截断；显示字段长度和上下文预算提示，由玩家决定精简。总体估算超过预算时仍允许保存，但明确警告模型上下文可能无法容纳全部状态。
- Chronicler 只有在持续剧情证据表明对象重要时才可直接建立追踪对象；提示词抑制无必要建对象。玩家可手动追踪、固定、归档或删除。
- 玩家可修改卡包字段的值，但不能在会话中修改字段定义；类型/范围/显示语义变化必须由卡包版本迁移或别名声明处理。已归档对象仍可被关系引用，关闭目标/矛盾/事件不连带删除对象或关系。
- fork 只继承实际已写入 fork 前缀的时间线事件；异步推演尚未写入的结果不伪造到子线。推演失败、无效或取消不生成 WorldState 变更事件；玩家矫正理由为可选说明。
- 推演期间仍可查看当前状态和时间线，但所有编辑控件禁用，并显示推演中状态；保存摘要按新增、修改、关闭、归档、删除分组，列出对象/字段和旧值/新值。
- Chronicler 可更新目标进度和排序建议；玩家可调整主目标与排序。目标/矛盾只有在剧情明确证据下关闭，玩家可关闭或重新打开；不因暂未提及自动关闭。
- 不保存模型内部推理；只保存可选的面向玩家的简短证据/变更说明。子线时间线区分继承的父线历史与本线事件，未知归因/回合可筛选并诚实显示未知；对象详情可打开对象或字段时间线，外部引用升级为追踪对象后才拥有对象时间线。
- 持久 WorldState Timeline 只记录实际世界状态变化；现有活动账本继续记录推演开始、失败、取消和无变化等运行事件，二者不合并。
- 卡包状态定义与初始状态分离，采用卡包级 schema；已声明字段使用卡包显示配置，未定义运行时字段使用框架通用显示并标记未定义。底层字段组件采用有限声明式组件，不允许卡包注入任意前端运行时。
- 对象详情统一包含身份/当前状态、卡包字段、关联事项、关系和对象时间线；关系可从任一参与对象详情独立编辑，不自动同步角色字段或认知。外部引用升级时保留引用历史；确认删除后，关联处降级为带原名称的外部引用，不级联删除剧情结构。
- 旧会话不承担新 WorldState 时间线或 schema 的兼容迁移；新建会话直接使用新模型。官方 `maid-heiress` 与 `yanmen-inn` 卡包作为首批迁移和验收样本。
- Chronicler 输出当前完整 WorldState 与面向玩家的变更摘要；框架比较前后状态生成字段差异。玩家保存按差异决定是否写入，但有变化时写入完整新快照；无变化不写 WorldState 时间线。一次玩家保存、一次 Chronicler 推演或一次月停获准动作各形成一个原子时间线批次。
- 卡包 schema 有独立版本号；字段改名、改类型、改范围必须有卡包迁移/别名声明，无声明则保留旧字段并标记定义不匹配。验收必须覆盖两张官方卡、双入口编辑、追踪对象、关系、目标、矛盾、认知、事件、Chronicler、时间线筛选、fork 和共享草稿。
- 字段、事件和角色认知支持 `player`、`model`、`hidden` 可见性；隐藏内容可供 Author 消费但必须遵守卡包秘密揭示规则，玩家界面只显示“不公开的世界信息”提示，不显示内容。玩家不能直接编辑不可见内容；月停只能按明确指令暂存建议，Chronicler 可根据剧情证据更新并保留归因。
- 玩家角色是特殊追踪对象，使用同一对象模型但单独标识；Author 不得替玩家生成行动、对白或心理。玩家可编辑认知命题与状态，但不因认知矫正自动改变客观事实。
