> 学习时间：2025-01-XX
> 预设规模：224 个提示词条目，启用 22343 字符
> 分析目的：为 dsh-rrp 的提示词质量优化提供参考

## 一、整体架构：五层结构

这个预设不是"一段长提示词"，而是**五层可组合的模块系统**：

| 层 | 作用 | 关键技术 |
|:---|:---|:---|
| **1. 变量层** | `{{setvar::xxx::...}}` 定义 60+ 变量 | SillyTavern 变量系统 |
| **2. 组装层** | `jailbreak` 条目用 `{{getvar}}` 拼装 | 模板引擎 |
| **3. 两阶段层** | `stage_1_base` + `stage_2_pre_output` | 分层递进 |
| **4. 思维链层** | `<think_fox~>` 包裹 18 步自检 | 结构化推演 |
| **5. 输出层** | `<content>` + `<fox_selc>` + `<fox_tip>` | 标签化输出 |

## 二、核心设计模式（值得借鉴）

### 2.1 变量化模块（最强设计）

整个预设用 60+ 个 `setvar` 定义可开关的模块：

```
{{setvar::wenfeng:: ...文风规则... }}
{{setvar::POV:: ...视角规则... }}
{{setvar::zhuanshu:: ...转述规则... }}
{{setvar::qianghua:: ...防抢话规则... }}
```

然后在组装层统一注入：

```
<writing_style>
{{getvar::wenfeng}}
</writing_style>
```

**价值**：玩家可以独立开关每个模块，不需要改主提示词。

### 2.2 两阶段递进

- **阶段一**（`stage_1_base_requirements`）：基础规则、文风、格式
- **阶段二**（`stage_2_pre_output_check`）：输出前检查，**优先级高于阶段一**

原文：
> 以下规则直接约束本轮输出，优先级高于第一阶段中的普通风格规则。

**价值**：解决"规则太多，模型记不住"的问题——关键约束放在最后，权重更高。

### 2.3 结构化思维链（最精妙）

要求模型在正文前输出 `<think_fox~>...</think_fox~>`，包含：

**部分零：角色感知边界（防全知）**
- 每个角色逐一列出：感知范围、合法信息来源、不可知信息
- 强制模型先想清楚"谁知道什么"，从源头杜绝全知 bug

**部分一：角色内心预演**
- 第一人称内心独白，星号与无星号交替
- 平缓场景 150-300 字，冲突场景 300-600 字
- 只写非 user 角色，禁止预演 user 内心

**部分二：导演检查（18 步硬规则）**
- 场景氛围、角色身体诚实度、潜文本、反套路、用户要求
- 18 条硬规则逐条过，禁止跳过或仅写"通过"

**价值**：把"隐性思考"变成"显式检查清单"，大幅降低低级错误。

### 2.4 反套路三重推翻

正文生成前必须输出三个模块的预演与推翻：

1. **人物预演与推翻**：列出脸谱化写法 → 逐一推翻
2. **剧情预演与推翻**：列出陈旧套路 → 逐一推翻
3. **句式预演与推翻**：列出 AI 句式 → 逐一推翻

明确点名要避免的 AI 腔：
- 五官套路、情绪套路、动作套路、比喻套路
- 破折号句式、副词堆砌、"不是……而是"句式

**价值**：直击 AI 写作的通病，用"先列后破"强制模型跳出舒适区。

### 2.5 具象化的写作指导

**文风示例（真实感）**：
```
情感只能通过外在呈现
错误："她很难过"
正确："她把那杯水端起来，顿住了，过了一会儿，又原样放了回去。"
```

**防全知示例**：
```
视觉：只写双眼所见。门后的景象，在推开门之前，只是未知。
内在感知：他人的心思，对方说出口了、写下来了，你才知道。
```

**价值**：用"错误 vs 正确"的对比示例，比抽象规则有效 10 倍。

### 2.6 字数分级控制

```
简单互动 → 1000-2000 字
正常推进 → 2000-4000 字
关系变化 → 4000-7000 字
冲突转折 → 7000+ 字
```

并明确禁止填充：
> 禁止用天气描写、家具陈列、路程经过、换装过程、无意义的等待或重复动作来填充。

**价值**：按场景类型动态调整篇幅，而非一刀切。

## 三、技术手法清单

| 手法 | 实现 | 价值 |
|:---|:---|:---|
| **变量系统** | `setvar`/`getvar` 60+ 模块 | 可开关、可组合 |
| **标签隔离** | `<content>`, `<think_fox~>`, `<fox_selc>` | 结构化解析 |
| **优先级声明** | "阶段二优先级高于阶段一" | 解决规则冲突 |
| **自检清单** | 18 步硬规则 | 降低低级错误 |
| **反例示范** | "错误 vs 正确"对比 | 具象化指导 |
| **防截断声明** | "必须完整生成后才允许终止符" | 对抗模型提前收尾 |
| **格式锚点** | `{{trim}}` 去除空白 | 精确控制 |
| **预填充** | assistant 角色预填 `OUTPUT` | 强制输出格式 |
| **技能引用** | 指向 `fox-nsfw-rules/` 等 Skill | 渐进披露 |
| **条件触发** | "仅当涉及 NSFW 时读取" | 按需加载 |

## 四、对 dsh-rrp 的启示

### 4.1 我们已经做对的

| 项 | 酒馆预设 | dsh-rrp | 评价 |
|:---|:---|:---|:---|
| 防全知 | 思维链"部分零" | 提示词第 4 条铁律（部分） | ⚠️ 我们较弱 |
| 防抢话 | `qianghua` 模块详细规则 | 提示词铁律 1（简略） | ⚠️ 我们较弱 |
| 转述规则 | `zhuanshu` 模块（详细） | ❌ 无 | ❌ 缺失 |
| 文风指导 | `wenfeng` + 具象示例 | 提示词简略要求 | ⚠️ 我们较弱 |
| 反套路 | 三重推翻机制 | ❌ 无 | ❌ 缺失 |
| 字数控制 | 四级分类 | ❌ 无 | ❌ 缺失 |
| Skills 按需 | ✅ 条件触发 | ✅ 我们已实现 | ✅ 对齐 |
| 前缀缓存 | ❌ 无优化 | ✅ 我们已实现 | ✅ 我们更强 |
| 结构化状态 | MVU 变量 | ✅ WorldState 投影 | ✅ 各有千秋 |

### 4.2 可借鉴的具体改进

**高价值（建议采纳）**：

1. **转述规则（zhuanshu）**
   - 区分"角色扮演输入" vs "指令元输入"
   - 明确对白原话必须保留，只调整标点
   - 括号内容视为高权重元指令

2. **防全知强化（extra4）**
   - 五感边界明确清单（视觉/听觉/触觉/内在感知）
   - "消息获取需有明确路径"原则
   - 身份/时代/世界三重认知限定

3. **反套路机制**
   - 人物/剧情/句式三重预演与推翻
   - 明确点名 AI 腔（破折号、"不是…而是"等）

4. **具象化示例**
   - "错误 vs 正确"对比示范
   - 情感只能通过外在呈现

**中价值（可选）**：

5. **字数分级**：按场景类型调整篇幅
6. **防截断声明**：对抗提前收尾
7. **思维链自检**：结构化检查清单

**不建议采纳**：

8. ❌ **变量系统**：SillyTavern 特有，DSH 用 Skills 更优
9. ❌ **jailbreak 条目**：突破安全限制，不符合 DSH 定位
10. ❌ **usage_policies 注入**：OpenAI 政策文本，与我们无关
11. ❌ **行动选项（fox_selc）**：这是"话痨"风格，与我们的沉浸定位不完全一致
12. ❌ **单一巨型提示词**：我们应保持分层（persona + skills）

## 五、关键洞察

### 5.1 酒馆预设 vs dsh-rrp 的本质差异

| 维度 | 酒馆预设 | dsh-rrp |
|:---|:---|:---|
| **形态** | 单一巨型提示词（22K 字） | 分层（persona + skills） |
| **知识** | 全部塞进上下文 | Skills 按需调取 |
| **状态** | MVU 变量 + 正则解析 | sessionProjections 纯数学折叠 |
| **成本** | 无优化（22K 字每轮全发） | 前缀缓存 + 按需加载 |
| **质量** | 极其精细的写作指导 | 相对简略 |

### 5.2 我们真正缺什么

**不是"缺提示词"，而是"缺写作质量的精细化指导"**。

具体差距：
1. ❌ 没有"错误 vs 正确"的具象示例
2. ❌ 没有反套路机制
3. ❌ 没有字数控制
4. ❌ 防全知和防抢话规则过于简略
5. ❌ 没有转述规则

### 5.3 但我们的架构更优

- ✅ 前缀缓存让成本可控（22K 字每轮全发是酒馆的致命伤）
- ✅ Skills 按需加载避免上下文堆砌
- ✅ 三智体分离（Author/Chronicler/Summarizer）
- ✅ 状态投影精确重放

**结论**：架构上我们领先，但提示词的"写作指导深度"需要补课。
