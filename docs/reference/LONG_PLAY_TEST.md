## 2. 每轮都要对照的横切检查

- [ ] **归因账本**：右侧「最近变更」出现 `纪事官 · 已更新状态` + 人类可读摘要（长局里不能断）
- [ ] **不出戏**：正文里没有"作者/助手/纪事官/AI"、没有解释规则、没有征求设定
- [ ] **不代打**：没有替玩家决定动作、对白或心理

### 量化发现（P1）与修复

- **现象**：`flags` 第 5 轮 10 项 → 第 10 轮 21 项 → 第 15 轮 **32 项**；底栏 token 3.4K → 41.9K → 133K → **227K**。
- **诊断**：纪事官把 `flags` 当**事件流水账**持续追加，宿主侧也无上限。
- **修复**（提交 `4eaab20`）：
  1. **提示词**：明确 WorldState 是「当前切面」——已解决/被取代的条目不保留（历史交给大局编年）；要求按重要度排序，`flags ≤ 20`；
  2. **宿主硬上限**：`pruneWorldState`（角色 24 / 物品 40 / flags 24 + 单值 160 字），在 `parseChroniclerReply` 出口强制生效。
- **诚实说明**：227K 的**大头是累积的对话正文与工具结果**，WorldState 只是其中一小部分。历史膨胀属宿主职责（`dsh-compaction`），我们不自建裁剪；本次解决的是**状态语义漂移 + 状态无界增长**。
