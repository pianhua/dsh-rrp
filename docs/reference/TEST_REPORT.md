## 发现的问题

### 问题 1：UI 面板存在未本地化的 i18n Key 裸露

- **严重程度**：🟢 低（体验细节）
- **复现步骤**：
  1. 打开右侧边栏「世界状态」标签页。
  2. 观察折叠区域标题及底部状态栏。
- **期望行为**：显示「核心状态」、「自定义字段」、「已开始推演」、「纪事官已完成」。
- **实际行为**：直接显示了裸 Key 字符串：
  - `section.coreState`
  - `section.dynamicFields`
  - `phase.started`
  - `chronicler.completed`
- **根因定位**：
  `src/client/world-state-tab.tsx` 中使用了形如 `title={t('section.coreState') || '核心状态'}`。因为 DSH 原生 `t()` 在字典中找不到对应 key 时默认返回 key 字符串本身（而非 `undefined`），导致 `|| '核心状态'` 默认值未被采纳；同时 `src/client/index.ts` 的 `zh` 字典未补入这些键的翻译。
- **截图 / 日志**：可见于 `docs/reference/acceptance-screenshots/d5-01-initial-state.png`。
