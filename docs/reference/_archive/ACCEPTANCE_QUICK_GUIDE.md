## ✅ 7 个关键验收点

### 1️⃣ Workspace 分组
- 不选 Workspace → Session 在未分组区
- 选择 Workspace → Session 正确归属

### 2️⃣ 同卡多存档隔离
- 同一张卡开两局
- 修改存档A的 World State → 存档B不受影响
- 设置存档A `/summary off` → 存档B仍默认 ON

### 3️⃣ Preset 验证与开场白
- 选卡 → 自动出现开场白
- 初始 World State 非空
- `/skill list` 可见卡包 Skills
- 手动传错误 `cardId` 到 `/start` → 被拦截

### 4️⃣ D8 典籍作用域
- 存档A创建典籍 "魔法阵原理"
- `/skill list` 新增动态 Skill
- 切换到存档B → 看不到该 Skill
- 刷新页面 → 存档A仍可见

### 5️⃣ Fork 继承与分流
- 存档A有典籍后，Fork 创建子局
- 子局继承父局消息、World State、典籍
- 子局修改/新增 → 父局不受影响
- 父局修改/新增 → 子局不受影响

### 6️⃣ 旧数据迁移
- 如有旧 sidecar：迁移后写 `sediment/snapshot`，留下 `.legacy.bak`
- 如无旧数据：标注 "无旧数据可测"

### 7️⃣ UI 响应式适配
- 宽屏（>= 1920px）+ 亮主题 → 无溢出/遮挡
- 窄屏（<= 768px）+ 暗主题 → 响应式布局正常
- 无控制台错误
