## D5 动态世界状态测试

### 测试目标

验证 Chronicler 能否成功创建动态字段，UI 能否正确显示和编辑。

### 测试步骤

#### 5.1 创建新会话

1. 打开 Web GUI
2. 创建新 RP 会话（使用默认卡包或测试卡）
3. 记录：Session ID

#### 5.2 触发 Chronicler 推演

1. 发送一条玩家消息（如："我查看周围环境"）
2. 等待 Author 响应完成
3. 观察右侧栏"最近变更"区域
4. 记录：
   - [ ] Chronicler 是否启动（显示"纪事官 · xxx"）
   - [ ] 推演是否完成（显示"已更新状态"）
   - [ ] 是否有错误日志

#### 5.3 验证核心状态更新

1. 打开右侧栏"世界状态"标签
2. 展开"核心状态"区域
3. 检查：
   - [ ] characters 字段是否有数据
   - [ ] scene 字段是否有数据
   - [ ] 数据是否合理（符合剧情）

#### 5.4 验证动态字段创建（关键）

**期望行为**：如果剧情涉及数值属性（如魔法值、声望），Chronicler 应该创建动态字段。

**测试方法**：
1. 发送消息："我施放了一个消耗魔力的法术"
2. 等待推演完成
3. 检查"自定义字段"区域：
   - [ ] 是否出现新字段（如 `magic_power`）
   - [ ] 字段类型是否正确（number）
   - [ ] 是否有约束（min/max）

**如果未创建动态字段**：
- 不是 bug，Chronicler 可能判断不需要
- 继续其他测试

#### 5.5 验证 UI 编辑功能

1. 在"自定义字段"区域点击"添加字段"
2. 填写：
   - 字段 ID: `test_field`
   - 类型: `number`
   - 初始值: `50`
   - 最小值: `0`
   - 最大值: `100`
3. 点击"添加"
4. 检查：
   - [ ] 字段是否出现在列表中
   - [ ] 是否可以编辑值
   - [ ] 修改值后点击"保存"是否成功

5. 修改字段值为 `150`（超出 max）
6. 点击"保存"
7. 刷新页面
8. 检查：
   - [ ] 值是否被 clamp 为 `100`

#### 5.6 验证字段删除

1. 点击字段旁边的删除按钮
2. 点击"保存"
3. 刷新页面
4. 检查：
   - [ ] 字段是否已删除

#### 5.7 验证字段 ID 校验

1. 尝试添加字段 ID: `invalid-id`（包含连字符）
2. 检查：
   - [ ] 是否显示错误提示
   - [ ] 是否阻止添加

3. 尝试添加字段 ID: `characters`（保留名称）
4. 检查：
   - [ ] 是否显示错误提示
   - [ ] 是否阻止添加

## D6 自然时序窗口测试

### 测试目标

验证 Chronicler 推演期间保存按钮被禁用，推演完成后自动重载。

### 测试步骤

#### 6.1 触发推演并立即尝试保存

1. 发送一条玩家消息
2. 在 Chronicler 推演期间（显示"纪事官推演中..."）：
   - [ ] 保存按钮是否禁用
   - [ ] 状态栏是否显示"纪事官推演中，请稍候..."
3. 推演完成后：
   - [ ] 保存按钮是否恢复可用
   - [ ] 状态栏是否显示"纪事官已更新状态"

#### 6.2 验证推演完成后的自动重载

1. 在 Chronicler 推演前，修改一个字段值（不保存）
2. 等待推演完成
3. 检查：
   - [ ] 修改是否被重载（恢复为推演后的值）
   - [ ] dirty 标记是否清除
   - [ ] 不会出现"未保存"提示

#### 6.3 验证推演失败的处理

**测试方法**：
1. 断开网络或停止模型服务（模拟推演失败）
2. 发送消息
3. 等待失败
4. 检查：
   - [ ] 保存按钮是否恢复可用
   - [ ] 是否显示错误提示
   - [ ] UI 是否正常可用

## 注意事项

### ❌ 禁止操作

1. **绝不修改代码**：发现问题只记录，不修复
2. **绝不执行危险命令**：如 `rm -rf`、`git reset --hard` 等
3. **绝不修改配置**：如 `package.json`、`.env` 等
4. **绝不干预 Session**：不手动删除 Session 数据

### ✅ 允许操作

1. 启动 / 停止 rp-dev
2. 创建 / 删除测试 Session（通过 UI）
3. 发送测试消息
4. 查看日志和状态
5. 截图记录问题

### 🔍 调试技巧

1. **查看控制台日志**：`pnpm run rp-dev` 的输出
2. **查看浏览器控制台**：F12 开发者工具
3. **查看 Session 事件流**：通过 DSH UI
4. **查看活动账本**：GET http://localhost:xxxx/dsh-rrp/activity?sessionId=xxx

### 📋 记录要求

每个测试项必须记录：
1. 测试时间
2. 操作步骤
3. 期望结果
4. 实际结果
5. 截图 / 日志（如有异常）
