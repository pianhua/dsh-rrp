# 写作指导 Skill 测试提示词

> 目的：验证 Author 是否按新规范写作，以及是否主动调用写作 Skill
> 环境：rp-dev，用 maid-heiress 卡

---

## 一、快速验证（3 轮，看基础规范）

### 第 1 轮：测"情感外在化"

```
我推门进来，看了米娅一眼，没说话，把外套挂在门口的架子上。
```

**观察点**：
- [ ] 是否写了米娅的**身体反应**（手、视线、呼吸），而不是直接说"她很紧张"
- [ ] 是否出现"她感到……""她心里……"这类直接写心理的句子（❌ 不该有）
- [ ] 是否替玩家补充了心理/未说出口的想法（❌ 不该有）

---

### 第 2 轮：测"输入处理 / 转述规则"

```
让她去洗衣服
```

**观察点**（这是元指令，不是台词）：
- [ ] 是否写成"米娅转身去洗衣服"这类 NPC 反应
- [ ] 是否错误地写成玩家说了"让她去洗衣服"这句话（❌ 不该有）
- [ ] 是否把括号/指令原文输出到正文（❌ 不该有）

---

### 第 3 轮：测"防全知"

```
我走到卧室，关上门。
```

**观察点**：
- [ ] 关上门后，是否还在描写客厅里米娅的内心活动（❌ 不该有）
- [ ] 是否只写了玩家能感知到的（门后的声音、光线等）
- [ ] 若写米娅那边的反应，是否用了"似乎/也许"等模糊词

---

## 二、深度验证（触发 Skill 调用）

### 第 4 轮：测"反套路"触发

```
我坐在沙发上，看着她走过来。
```

**观察点**：
- [ ] 是否出现 AI 腔（"不是……而是……"、"轻轻地、缓缓地"、破折号滥用）
- [ ] 是否出现五官轮播式描写
- [ ] 米娅的反应是否有**个性**，换个角色也成立就说明没写好

**检查是否调用了 anti-cliche**：
查看 DSH 的技能调用记录或会话事件流，看是否出现 `anti-cliche` 调用。

---

### 第 5 轮：测"复杂场景"触发

```
我拿起电话，是家里来的。米娅在旁边擦桌子。
```

**观察点**（两个角色 + 信息不对称）：
- [ ] 米娅是否**偷听**了电话内容，或只是"听到模糊的声音"
- [ ] 玩家电话里的内容是否只写玩家知道的
- [ ] 是否出现"米娅心里想……"这类越界描写

**检查是否调用了 narrative-boundaries**。

## 四、给测试者的说明

**测试方式**：新建 maid-heiress 会话，依次发送上述 5 条消息。

**重点看**：
1. 有没有"直接写心理"（应该通过身体动作表现）
2. 有没有"替玩家说话/做事"（绝对禁止）
3. 有没有"越界知道不该知道的事"（防全知）
4. 有没有明显的 AI 腔

**关于 Skill 调用**：
- Skill 是模型自主判断调用的，没调用不一定是 bug
- 如果多轮都没调用，说明 persona 的引导需要加强
- 记录实际调用情况即可，不要人为干预

**只读原则**：观察记录，不改代码。
