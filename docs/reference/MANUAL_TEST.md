## 0. 启动实例

```bash
cd /d/projects/dsh-rrp && pnpm run build
dsh --profile rp-dev --port 3099 --no-open
# 打开日志末尾打印的 http://127.0.0.1:3099/?token=… 链接
```

启动日志应包含：

- `activity ledger projection registered (key 'rrpActivity')`
- `active-card projection registered (key 'rrpCard')`
- `card routes armed` / `card start route armed`
- **`RP skills visible (6): maid-apartment, maid-cecilia, maid-family, maid-mia, maid-tone-rules, maid-world-setting`**

### 缺陷与修复

- **现象**：卡片展厅点「开始这一局」报 `cannot get property "remote.agentPresets" without inject`。
- **根因**：Cordis Remote 代理是**命名空间服务**，只声明 `'remote'` 不够，必须显式声明 `'remote.agentPresets'`
  （宿主 `dsh-client-ui-agent-preset/lib/client.js:1397` 即如此声明）。
- **修复**：`src/client/index.ts` 的 `inject` 数组加入 `'remote.agentPresets'`（提交 `69611c6`）。
- **状态**：已复测通过（点「开始这一局」直接成功）。
