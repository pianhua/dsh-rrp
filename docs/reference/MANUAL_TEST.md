# MANUAL_TEST.md — 实机验收清单

> 自动化测试不含浏览器渲染与真实模型；下列项目必须由所有者在 `rp-dev` 实例上人工确认。
> 每次改动相关区域后重跑本表。

## 0. 启动实例

```bash
cd /d/projects/dsh-rrp && pnpm run build
dsh --profile rp-dev --port 3099 --no-open
# 打开日志末尾打印的 http://127.0.0.1:3099/?token=… 链接
```

启动日志应包含：

- `activity ledger projection registered (key 'rrpActivity')`
- `active-card projection registered (key 'rrpCard')`
- `card routes armed` / `card start route armed`
- **`RP skills visible (6): maid-apartment, maid-cecilia, maid-family, maid-mia, maid-tone-rules, maid-world-setting`**

## 1. 主题（P0）

- [ ] 刷新页面后整体为**暖纸色 + 衬线正文 + 较大行高**；
- [ ] 明暗主题切换后都可读（可在 设置 → 外观 切换）；
- [ ] 关掉/卸载插件后主题恢复（override 层可逆）。

## 2. 卡片展厅（P2）

- [ ] 左侧边栏出现「**卡片展厅**」导航图标；
- [ ] 点开后主区显示卡包列表，含「**女仆大小姐**」；
- [ ] 选中后右侧显示：简介、标签、玩家角色、6 个世界知识、开场白全文；
- [ ] 点「刷新」不报错。

## 3. 开卡开局（P2，关键）

- [ ] 点「**开始这一局**」后切到一个新会话，标题为「**女仆大小姐**」；
- [ ] 开场白以**正文第一条**出现（若是折叠的「序章」上下文行，说明宿主拒绝了 `assistant/message`，记录之）；
- [ ] 右侧「世界状态」立即显示：米娅（好感 6）、场景「平民公寓 · 门口」、3 条事件；
- [ ] 「最近变更」显示 **卡包 · 初始状态**。

## 4. 卡包设定是否真的进了作者（关键）

发一句行动（如「我去开门」），然后在轨迹/请求检查里确认作者的前置上下文包含：

- [ ] `【当前卡包 · 设定基准】`（卡名、玩家角色、世界核心、人设规则）；
- [ ] `【世界状态 · 事实基准】`；
- [ ] 作者正文**遵守卡包设定**（不凭空换世界观、不自称「纪事官/作者」）。

## 5. 技能检索（D7）

- [ ] 剧情触及家族/公寓/塞西莉亚时，模型能通过 `skill` 工具调取到 `maid-*` 技能；
- [ ] 轨迹里能看到 `available_skills` 含这 6 个技能。

## 6. 状态归因与矫正（二测修复）

- [ ] 一轮结束后，右侧「最近变更」出现 **纪事官 · 已更新状态** + 人类可读摘要；
- [ ] 就地修改某个数值并「保存矫正」，下一轮作者按新值起笔；
- [ ] 保存后「最近变更」出现 **你 · 已就地矫正**。

## 7. 已知风险

- [ ] **秘密剧透**：卡包设定含「米娅是财阀千金」这一核心秘密。若它出现在**聊天正文**（而非只在轨迹/请求检查里），立即报告——需要改为纯 Skill 承载。
- [ ] 开场白 `assistant/message` 若被宿主拒绝，会回退成 plugin notice；两种情况都请记录。
