# 条件注入机制 v1 · 实现计划（PLAN）

> **状态**：设计已对齐（2026-09-19），待动工
> **对应 issue**：#16 · 给 skills 渐进披露的方差兜底
> **一句话定义**：程序对世界状态求值，命中即把设定片段以「裁决式注入块」确定性写进 facts 通道；模型无权跳过。不是酒馆关键词扫描（不读正文），不只是分阶段人设（那只是应用之一）。

## 已拍板的设计决策

| 决策点 | 结论 |
|---|---|
| 载体 | `SKILL.md` frontmatter 可选 `when: 条件`（机制与内容分离：框架写一次，卡作者只写声明数据） |
| 数据源 | 仅 WorldState 投影，纯数值判断；剧情理解永远归模型 |
| 注入形态 | **裁决式注入块**：指令为壳（当前生效档位 + 调用纪律 + 失效撤销句）、片段为载荷（单条 800 / 总量 2000 字符封顶，按声明顺序截断） |
| 缓存纪律 ① | 块文本只依赖命中**集合**，不嵌实时数值（档内波动零发布，仅跨档发布） |
| 缓存纪律 ② | 命中集合由非空变空时，新块渲染失效撤销句，买断旧块残留污染 |
| 权威 | 服从 persona 既有「最新状态优先」裁决；append-only 尾部追加，指纹去重复用 |
| 语法 v1 | `when: characters.米娅.affinity >= 80` / `flags.X == true` / `scene.location == "雁门关"`；运算符 `> >= < <= == !=`；非法语法加载时报错定位 |
| 扩展性 | 三吸收点：①语法解析器 ②数据源（新信号以投影字段进入，永不扫正文） ③注入块渲染；语法向后兼容，老卡永不返工 |
