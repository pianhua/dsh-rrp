# 条件注入机制 v1 · 实现计划（PLAN · 修订版 R1）

> **状态**：设计已对齐 + 第三方评审修订（2026-09-19），待动工
> **对应 issue**：#16 · 给 skills 渐进披露的方差兜底
> **一句话定义**：程序对世界状态求值，命中即把设定片段以「裁决式注入块」确定性写进 facts 通道；模型无权跳过。不是酒馆关键词扫描（不读正文），不只是分阶段人设（那只是应用之一）。
>
> **修订记录（R1，第三方评审五条风险全部采纳）**：
> - 风险 1：验收标准「档内波动零发布」与 facts 通道现状矛盾 → 改为「注入块文本只由命中集合决定，档内波动逐字节不变」；facts 随状态重发是现状，不归本机制管
> - 风险 2（命门）：字符串等值 × Chronicler 自由文本写值 = 静默失配 → **v1 语法砍掉字符串比较，仅允许数值/布尔**；字符串等值留 v2 且须配词表写入 Chronicler 契约 + zod 强校验才解锁
> - 风险 3：`when` 路径加载时对照 state.json 键树存在性检查，缺失 warn 点名（T5 扩展）
> - 风险 4：命中集与截断顺序按 skill id 字典序，消灭 readdir 不确定性（T2 锁死）
> - 风险 5：注入块外壳加穷尽性声明「仅本块所列条目有效，此前所有条件注入一律作废」（T3 扩展）
> - T7 修正：设定集页签新增「卡包条件设定」只读区（与会话知识条目分区），原「active 标」落在此处

## 已拍板的设计决策

| 决策点 | 结论 |
|---|---|
| 载体 | `SKILL.md` frontmatter 可选 `when: 条件`（机制与内容分离：框架写一次，卡作者只写声明数据） |
| 数据源 | 仅 WorldState 投影，纯数值判断；剧情理解永远归模型 |
| 注入形态 | **裁决式注入块**：指令为壳（当前生效档位 + 调用纪律 + 失效撤销句）、片段为载荷（单条 800 / 总量 2000 字符封顶，按声明顺序截断） |
| 缓存纪律 ① | 块文本只依赖命中**集合**，不嵌实时数值（档内波动零发布，仅跨档发布） |
| 缓存纪律 ② | 命中集合由非空变空时，新块渲染失效撤销句，买断旧块残留污染 |
| 权威 | 服从 persona 既有「最新状态优先」裁决；append-only 尾部追加，指纹去重复用 |
| 语法 v1 | `when: characters.米娅.affinity >= 80` / `flags.身份已暴露 == true`；**仅数值与布尔比较**（`> >= < <= == !=`）；字符串比较 v2 解锁（须配 Chronicler 词表契约 + zod 校验）；非法语法加载时报错定位 |
| 扩展性 | 三吸收点：①语法解析器 ②数据源（新信号以投影字段进入，永不扫正文） ③注入块渲染；语法向后兼容，老卡永不返工 |
| 排序纪律 | 命中集与截断一律按 **skill id 字典序**，指纹跨平台稳定 |
| 穷尽声明 | 每个注入块外壳含「仅本块所列条目有效，此前所有条件注入一律作废」，换档/失效都不留残留 |

## v1 明确不做（扩展点记账）

多条件组合（and/or）、失效迟滞（阈值抖动 79↔80 横跳，真机出现后做）、互斥组声明（frontmatter `group:`）、回合数数据源、**字符串比较**（v2 解锁条件：允许值词表写入 Chronicler 输出契约 + zod 强校验）。

## 已知并放弃（记入 DECISIONS D17）

- **双通道重复**：模型语义调取命中 skill 全文 + 条件注入其 800 字片段 = 同一内容两份。v1 接受（注入块自带「无需再调」纪律，重复读取是浪费而非错误）。
- **字符串自由文本不设条件源**：自由文本的词表漂移会让保下限静默失效（评审风险 2）；身份揭穿类场景一律建模为布尔/数值字段。
