# 规格 · 展厅 v2 重做（gallery-v2）

> 决策真源：DECISIONS.md **D26**（2026-09-27 拍板，15 题拷问确认）。术语：GLOSSARY「封面 / Cover」「卡片展厅」。
> 视觉参照：SillyTavern 角色选择界面（本地只读勘察 `C:\Users\10697\Desktop\pian\SillyTavern-release`，仅借鉴设计不复制代码）。

## 目标（一句话）

把卡片展厅从「列表 + 表单」重做為「封面网格墙 + 滑出详情」的角色选择体验，并建立声明式封面（立绘）管道；一期纯视觉与信息架构，不动玩法功能面。

## 用户可验证行为

### B1 封面网格墙

- 主区展示所有卡包的封面网格（含搜索过滤与刷新保留选中）。
- 每个网格单元：封面图 + 卡名 + 一句话简介；激活态有明确高亮（描边/光晕）。
- 响应式列数：宽窗多列 → 窄窗收缩到 1–2 列；卡数少时不空旷（单元最小宽度保证）。
- 点击单元：右側滑出详情面板（网格保留在背景）；关闭/Esc 返回纯网格。

### B2 封面（立绘）管道

- 卡包 `card.md` frontmatter 可声明 `cover: <ui/ 内相对路径>`（白名单扩展名：png/jpg/jpeg/webp/gif，与卡包界面资产一致）。
- 声明非法（路径穿越 / 文件不存在 / 扩展名越白名单）→ 解析警告 + 该卡回退占位封面，**不阻断卡加载**。
- 未声明 → 回退占位封面（升级版渐变 + 首字母，样式统一进网格单元）。
- 封面 URL 复用现成卡包界面路由 `/dsh-rrp/card-ui/<card>/<file>`，**零新路由**。
- 酒馆 PNG 导入：自动把上传的 PNG 本体存为新卡包的 `ui/assets/cover.png`（PNG 本身就是立绘，tEXt chunk 只是数据）；JSON 导入无内嵌图 → 回退占位。

### B3 详情面板层级（自上而下）

1. Hero：大封面 + 名称 + 简介 + 标签 + 作者/版本（有则显示）；
2. 开场白：多开局下拉（>1 个时）+ 正文预览（保留 #31-A 行为：预览即所得）；
3. 技能 chips（数量 + 名称/描述）；
4. 玩家角色：只读展示卡声明的主角，附提示「局内可在世界状态页签修改」；
5. 底部开始条：状态行 + 主按钮。

### B4 移除项（本期的减法）

- 展厅不再渲染主角名覆写输入框（#25）与自设人设 textarea（P1-B）；
- `start()` 客户端流不再传 name/persona 覆写；新局一律用卡声明主角（`player` 动态字段局内编辑保留，二期「主角编辑区」单独立票）；
- 服务端 `/dsh-rrp/start` 契约保持兼容（仍收 `card.player`，只是客户端永远传卡声明值）。

### B5 保留行为（位置随布局重做，行为不变）

- 搜索过滤（名称 + 简介 + 标签）、刷新保留选中（R18 语义，网格态下保留「选中卡 + 详情打开」状态）；
- 导入入口（PNG/JSON，落用户卡目录）、酒馆卡导入转译；
- 多开场白选择；一卡一区自动归属（失败降级不阻塞）、开局自动跳转、主线自动命名。

## 契约变更

| 契约 | 变更 |
| :--- | :--- |
| `card.md` frontmatter | 新增可选 `cover`（ui/ 相对路径） |
| `CardMeta` | 新增可选 `cover?: string`（ui 相对路径；客户端拼 `/dsh-rrp/card-ui/<id>/` 前缀） |
| `GET /dsh-rrp/cards` · `GET /dsh-rrp/card` | 响应带 `cover`（有声明且合法时） |
| 路由 | 零新增；封面伺服复用 `/dsh-rrp/card-ui` 双形态 |
| locale | `gallery.*` 键重排：新增封面/网格/详情相关键，删除 name/persona 相关键；`locale-keys.spec.ts` 守卫保持全绿 |
| `/dsh-rrp/start` | 请求体不变（客户端行为变化，非契约变化） |

## 异常与边界

- 卡列表为空 / 搜索无匹配 / 加载失败：三态均重设计但语义不变；
- 封面图加载失败（服务端 200 但图片损坏）：`onerror` 回退占位封面；
- 窄窗口（< 640px）：详情面板全幅覆盖网格；
- 暗/亮主题：全部走 `--dsw-alias-*` token，双主题可读；
- 酒馆 PNG > 导入限额（32MiB）：按既有 413 拒绝，不特殊处理。

## 验收条件

1. **组件测试（happy-dom）**：网格渲染、封面回退链（声明合法 / 声明非法 / 无声明 / onerror）、开场白选择、搜索过滤、详情层级顺序、**无主角名/人设控件存在断言**、刷新保留选中。
2. **解析/导入测试**：cover 字段合法/非法/穿越用例；PNG 导入落盘 `ui/assets/cover.png` 断言；JSON 导入无封面断言。
3. **发布门**：沿用既有卡包发布门模式，官方卡零外链约束不变。
4. **质量门**：`check:environment` / `format:check` / `typecheck` / `lint` / `pnpm test` / `build` / `git diff --check` 全绿。
5. **真机验收（内置浏览器 MCP）**：按 `dsh-rrp-test-report/` DEF 清单逐项核对（网格、封面、详情、开局流、双主题、窄窗），截图归档；最终观感所有者拍板。

## 视觉设计参数（ST 勘察落地，票据 02 执行依据）

> 勘察对象：`SillyTavern-release` 角色管理（右侧抽屉 `#rm_characters_block`）与 Character Browser 弹窗；仅借鉴设计，不复制代码（D16 同一协议纪律）。

- **网格单元**：竖版封面（2:3，`object-fit: cover`、`object-position: top` 照顾立绘）+ 卡名（单行省略）+ 一句话简介（单行省略，0.8 级字色）；封面圆角 + `border-l1` 细边框（ST 头像圆形 + 主题边框语汇的立绘化改法）。
- **信息降噪**：网格态不显示标签/技能等次级信息（ST 网格模式隐藏描述/标签的同一逻辑）；标签/技能只在详情面板出现。
- **激活/hover 低成本表达**：hover = `interactive-bg-hover` 半透明底、无位移；选中 = `border-l2` + 品牌色描边（不做复杂徽标）。
- **详情面板**：右侧滑出（ST 编辑面板在右侧的同一逻辑），主层级放 Hero/开场白/技能/主角/开始；作者与版本降为 Hero 内的次级小字（ST 把次要元信息折叠的同一逻辑）。
- **顶栏**：搜索框默认收起为图标、点击展开（ST 搜索默认隐藏逻辑），与刷新/导入同排；窄窗全部收进溢出菜单。
- **空态/加载/失败**：沿用 ST「低噪声」原则——骨架屏只给封面矩形 + 两行文字，不用花哨动画。
