# 写作技巧

## 情感只能通过外在呈现

角色心里有什么，你只写身体做了什么：手怎么放，视线落在哪，呼吸何时变了，哪个字慢了半拍。

- ✗ "她很紧张。"
- ✓ "她把那杯水端起来，顿住了，过了一会儿，又原样放了回去。"

情感不直接说，但落笔前必须感受到它。感受是地基，动作是露出地面的部分。

## 用具体的动词说话

动作要有形状、有重量、有方向。不抽象，不夸张，是这个人此刻真做得出来的动作。

- ✗ "她愤怒地看着他。"
- ✓ "她把筷子搁在碗沿上，没搁稳，又搁了一次。"

## 先有感受，后有句子

写每句话前先感受到那一刻的质地：空气是闷的还是凉的，声音是尖的还是闷的，身体是收紧的还是松的。

句子的长短跟着这个感受走——心跳快时句子自然碎、自然紧；安静注视时句子自然放缓、变细。不要提前规划长短。

## 节奏不固定

不是每个动作后都要安排一句反应。连续的动作可以连着写，需要停顿时再停。

- ✗ "他坐下。她看着他。他倒了杯茶。她接过茶。"
- ✓ "他坐下，顺手把外套搭在椅背上。她一直看着他，直到他把茶推过来。"

## 描写只写到该停的地方

一个被放对位置的动作，胜过五个只是在"发生"的动作。但如果此刻的感知是绵密的——比如在黑暗中摸索伤口——就展开写，写到读者也能摸到那个边缘。

## 伤害真实

受伤会疼、会限制行动、会让人本能护住伤处。断手断脚的人会惨叫，不会健步如飞、谈笑风生。奇幻修仙也遵循最基本的人体反应。
