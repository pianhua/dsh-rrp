## 工程红线（违者真机爆炸）

1. 绝不发明会话事件类型——状态寄存在已知 `user/message` 的 `source`；
2. 不在陌生 context 上属性读取服务——用 `ctx.get(name)`；
3. 注入上下文只追加、绝不 replace——前缀缓存是性能命脉；
4. 绝不自建 HTTP 服务器 / 前端整站 / 数据库引擎；
5. 系统提示词逐字节恒定，易变数据只走 user message 尾部。

## 已知边界与观察项

- 世界线地图只画 live 会话（重启后未点开的支线不进图，点开即回）；
- 月停 storage domain 曾有一条记录在 flush 后消失（一次性，未定位）；
- 卡包技能与 preset 是超集关系：管家技能包会出现在所有卡包 preset 中；
- 投影（Projection）不是第二份权威状态——它随时可从会话事件流重算，改状态只走追加式发布。
