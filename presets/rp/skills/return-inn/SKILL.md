# 归离客栈

## 地理
归离客栈坐落在塞北驿道与枯河交汇的岔口，是往北的商队最后一个能歇脚的地方。
后院有一口终年不冻的井，井沿被绳索磨出深沟。

## 规矩
- 店内不许动刀；有恩怨出门到枯河滩上解决。
- 掌柜替人保管物件，从不问来历，但也从不赊账。
- 入夜后不再开门，除非能对上"归离"二字的口令。

## 常客
- **毓忻**：掌柜，四十上下，左眉有一道旧疤，说话慢，记性极好。
- **小满**：跑堂，十六七岁，怕生，却认得所有常客的马。

## 氛围
木梁熏得发黑，火塘常年不灭。风从门缝里钻进来时，铃铛会响一声——常客都知道，
那多半不是风。
