## 2. 环境准备（严格执行）

1. `cd D:\projects\dsh-rrp && pnpm run build`（必须先重新构建）；
2. 若 3099 端口被占用，先杀进程再启动；
3. 启动：`dsh --profile rp-dev --port 3099 --no-open`（**禁止使用 3080 端口**）；
4. 等待就绪后核对：
   - 宿主日志出现 `copilot route armed` 字样（副驾路由挂载成功）；
   - 打开 `http://127.0.0.1:3099`，Console 无未捕获报错；
   - 进入任意 RP 会话（推荐先开「落魄大小姐女仆 · 米娅」卡，剧情互动多轮），右侧栏应出现**三个页签**：世界状态 / 典籍 / **副驾驶**。

**已知可接受的日志**：非 RP 会话返回 403 时的常规网络日志不算错误。
