## 五、环境性插曲（非缺陷，记录在案）

排查 T44 时发现副驾与 Chronicler 的 `ctx.llm.stream` 调用全部空响应，而 Author（agent 管线）正常——一度疑似回归。二分排除提示词后，定位根因：**环境变量 `ALL_PROXY=socks5://127.0.0.1:7890`（Clash）**，宿主对 SOCKS 不支持并回退直连，导致 llm 直连路径静默清空（宿主日志原话：`all_proxy names a SOCKS proxy, which is not supported; connecting directly for that scheme`）。**无代理环境重启后全部恢复**。教训：真机测试前若本机代理为 SOCKS 模式，需 `env -u ALL_PROXY …` 启动宿主；agent 管线与 llm 直连接口对代理的处理不一致。
